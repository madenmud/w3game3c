# w3game3c · 테크 삼국지

가상 아바타로 스타트업을 세우고, 직원에게 업무를 맡기고, 투자를 받으며 세 거대 진영의 패권을 다투는 자동 진행형 소셜게임입니다.

- 설계 문서: `docs/design-v0.1.md`
- 체험판: https://madenmud.github.io/w3game3c/

## 체험판(MVP) 범위

브라우저 하나로 혼자 한 시즌(56개월)을 플레이합니다. 서버 없이 정적 페이지로 돌고, 저장은 브라우저 localStorage에 합니다.

### 밸런스 장치

평가에서 찾은 악용·함정 전략을 막기 위해 넣은 규칙이다. `src/engine/balance.test.ts`의 전략 봇이 시드 12개로 매번 확인한다.

- 회사 가치에 보유 현금을 넣고, VC는 최근 3개월 MRR 성장률만큼(최대 +60%) 웃돈을 준다. 투자금은 채용과 월 광고 예산(체감하는 획득 단가)으로 성장에 쓴다.
- 월급은 시장가 70% 아래로 못 깎고, 깎으면 만족도가 바로 떨어진다.
- 크런치는 2개월까지만 성과 +20%이고, 더 이어지면 번아웃으로 보너스가 줄며(최저 0.8배) 만족도·분위기가 더 떨어진다.
- 한 업무에 성과가 몰리면 체감한다(10 초과분은 (합/10)^0.8). AI 점수는 객단가를 최대 +50% 올린다.
- 창업 직후 오너 기본 업무는 개발·기획·영업·마케팅 중에서 정한다. 오너가 학습 카드를 맞힌 달은 팀 전체 성과 +10%.

### 이번 달 결단과 참모 조언

삼국지의 군의·진언과 Reigns의 대가 있는 선택을 참고했다. 2개월차부터 매달 회사 상황에 맞는 카드 하나가 나오고(같은 카드는 10개월 안에 다시 안 나옴), 고르지 않고 정산하면 기본 선택지가 적용된다.

- 참모 조언: 카드 분야 능력치가 높은 직원 최대 3명이 자기 성향(능력치)에 맞는 선택을 추천한다. 성공 확률이 있는 선택은 분야 능력치가 높을수록 정확하게 말한다(오차 ±4~30%p). 만족도 35 미만인 직원은 조언하지 않는다.
- 몇 달짜리 효과(맞춤 개발, 가격 전쟁, 통합 작업 등)는 다음 정산 예상에 바로 반영된다.
- `src/engine/dilemmas.test.ts`가 카드마다 선택지별로 시즌을 끝까지 갈라 돌려, 한 선택지가 90% 넘게 이기지 않는지(정답이 상황마다 다른지) 확인한다. 30판 기준 참모 다수결로 고르면 방치보다 약 60% 높다.

## 개발

```bash
npm install
npm run dev      # http://localhost:5173/w3game3c/
npm test         # 규칙·밸런스 테스트
npm run build
```

- `src/engine/` 정산 엔진(순수 함수, 결정적 난수). 나중에 Cloudflare Workers에서도 그대로 쓴다.
- `src/engine/bots.ts` 밸런스 검증용 자동 플레이어.
- `src/ui/` 화면(프레임워크 없이 TypeScript).

## 배포

`main`에 머지하면 GitHub Actions가 테스트·빌드한 뒤 결과를 `gh-pages` 브랜치에 올리고, GitHub Pages가 그 브랜치를 서빙합니다.
